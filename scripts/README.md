# Scripts Directory

This folder contains utility scripts for project setup and maintenance.

## Files

- `create_default_image.py` - Creates a default profile image
- `fix_default_image.py` - Fixes corrupted default image
- `fix_default_image_final.py` - Final version of default image fix script

## Usage

Run these scripts from the project root directory:

```bash
python scripts/fix_default_image_final.py
```
